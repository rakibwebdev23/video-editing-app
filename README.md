# Video Creator — Professional Video Suite

A high-fidelity, browser-based video editing application built with Next.js 15, FFmpeg.wasm, and GSAP.

## 🚀 Features
- **Real-time Timeline**: Precise frame-by-frame editing with a 30 FPS playhead.
- **WASM Rendering**: Industry-standard H.264/MP4 export directly in the browser.
- **Smart Layouts**: Automatic grid and split-screen arrangement for media clips.
- **Permanent Vault**: Media files are stored in IndexedDB, surviving browser refreshes.
- **Motion Graphics**: Professional GSAP-powered transitions and animations.

## 🛠️ Technology Stack
- **Next.js 15** (React 19)
- **Redux Toolkit** (State Management)
- **FFmpeg.wasm** (Video Encoding)
- **GSAP** (Animations)
- **IndexedDB** (Persistent Media Storage)

## 📦 Installation & Setup

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Development Mode**:
   ```bash
   npm run dev
   ```

3. **Production Build**:
   ```bash
   npm run build
   npm run start
   ```
